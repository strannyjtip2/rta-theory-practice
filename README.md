# RTA Dubai Theory Practice (unofficial)

## Open on phone
1. **Single file (best offline-ish):** open `RTA-Theory-Practice.html` in the phone browser
   (Chrome/Safari → Files / Downloads → Open with browser). Sign images need internet
   (loaded from theorytest.ae).
2. **Full folder:** serve `/workspace/rta-exam-app/` (index.html + questions.json + img/).
   Includes service worker for caching after first load.

## Modes
- Exam: random 40 from full 1135 bank, shuffled options, 30 min, pass ≥30.
- Practice: all questions by topic (65 topics) or all shuffled; no timer.
- English first; Russian + correctness only after answer.

## Rules used
- 40 questions, ≥30 correct — RTA FAQ (rta.ae Knowledge Test service, updated Oct 2026).
- 30-minute timer — common practice apps; RTA page does not state a time limit.
- No hazard-perception video clips in this bank.
